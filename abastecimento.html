Conexão com o banco de dados (Firebase)
Pegue esses três valores no console do Firebase, em Configurações do projeto → Seus apps → Configuração do SDK. Depois clique em Gerar, e suba o firebase-config.json no repositório, ao lado do HTML. Isso é feito uma vez só — daí em diante todos os aparelhos se conectam sozinhos.
Envio para o GitHub
O token fica guardado só neste navegador e nunca entra no arquivo publicado. Crie em GitHub → Settings → Developer settings → Personal access tokens → Fine-grained, com acesso só a este repositório e permissão Contents: Read and write.
